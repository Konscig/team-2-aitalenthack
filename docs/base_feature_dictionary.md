# Base market feature dictionary

Источник: только реальные наблюдения из `data/interim/fx_quote_time.parquet`, полученные из официального web-service Банка России. Единица `rate`: RUB за 1 единицу валюты получателя. Поэтому меньший курс выгоднее отправителю RUB. Все окна измеряются в последовательных официальных quote observations, а не календарных днях. Все признаки имеют `uses_future = false`.

| name | formula | window | interpretation | uses_future |
| --- | --- | --- | --- | --- |
| `ret_N`, N ∈ {1,2,3,5,10,20} | `P_t / P_(t-N) - 1` | N предыдущих котировок | Относительное изменение курса; отрицательное значение выгодно отправителю RUB | false |
| `log_ret_1` | `ln(P_t / P_(t-1))` | 1 предыдущая котировка | Логарифмическое однопериодное изменение | false |
| `sma_N`, N ∈ {5,10,20,60} | `mean(P_t...P_(t-N+1))` | N, включая T | Скользящий средний уровень курса | false |
| `dist_sma_N`, N ∈ {5,10,20,60} | `P_t / sma_N - 1` | N, включая T | Положение текущего курса относительно среднего | false |
| `sma_5_vs_20` | `sma_5 / sma_20 - 1` | 5 и 20 | Короткий тренд относительно среднего | false |
| `sma_20_vs_60` | `sma_20 / sma_60 - 1` | 20 и 60 | Средний тренд относительно длинного | false |
| `rolling_min_N`, N ∈ {10,20,60,90,180,365} | `min(P_t...P_(t-N+1))` | N, включая T | Минимальный курс в trailing-окне | false |
| `rolling_max_N`, N ∈ {10,20,60,90,180,365} | `max(P_t...P_(t-N+1))` | N, включая T | Максимальный курс в trailing-окне | false |
| `dist_min_N`, N ∈ {10,20,60,90,180,365} | `P_t / rolling_min_N - 1` | N, включая T | Насколько курс выше локально лучшего уровня | false |
| `dist_max_N`, N ∈ {10,20,60,90,180,365} | `P_t / rolling_max_N - 1` | N, включая T | Положение относительно локально худшего уровня | false |
| `percentile_N`, N ∈ {20,60,90,180,365} | `mean(P_i <= P_t), i=t-N...t-1` | строго N прошлых, T исключён | Доля прошлых курсов не выше текущего | false |
| `favourability_percentile_N`, N ∈ {20,60,90,180,365} | `1 - percentile_N` | строго N прошлых, T исключён | Чем выше, тем выгоднее текущий низкий курс отправителю RUB | false |
| `mom_N`, N ∈ {3,5,10,20} | `P_t / P_(t-N) - 1` | N предыдущих котировок | Momentum курса; отрицательный означает снижение RUB-цены валюты | false |
| `down_streak` | число последовательных `P_i < P_(i-1)`, заканчивающихся в T | с последнего неснижения | Длина серии снижений по реальным котировкам | false |
| `up_streak` | число последовательных `P_i > P_(i-1)`, заканчивающихся в T | с последнего нероста | Длина серии ростов по реальным котировкам | false |
| `vol_N`, N ∈ {5,10,20,60} | `sample_std(log_ret_1, N)`, `ddof=1` | N последних лог-доходностей | Неаннуализированная волатильность | false |
| `rolling_range_N`, N ∈ {10,20,60} | `(rolling_max_N - rolling_min_N) / rolling_mean_N` | N, включая T | Нормированный диапазон курса | false |

Warm-up значения сохраняются как `NaN`: pipeline не заполняет их и не придумывает историю. Никакие centered windows, отрицательные `shift`, future values или глобальные статистики не используются.
