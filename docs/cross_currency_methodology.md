# Cross-currency methodology

## Направление и источники

Все исходные ряды взяты из `data/interim/fx_quote_time.parquet` и содержат только реальные официальные котировки Банка России. `X_RUB` и `USD_RUB` здесь означают соответственно RUB за 1 X и RUB за 1 USD. Поэтому:

```text
recipient_usd_implied = X_RUB / USD_RUB
```

имеет размерность USD за 1 единицу валюты получателя. Это implied cross-rate, вычисленный из двух официальных RUB-котировок, а не отдельная рыночная котировка.

## Alignment и freshness

Временная ось результата — реальные quote observations целевой валюты. Для каждой даты T ряды USD, EUR и CNY присоединяются as-of методом: выбирается последняя официальная котировка с датой `<= T`. Будущие значения и backward fill запрещены. Это causal forward fill последнего известного значения между несовпадающими датами публикации.

Сохраняются `usd_rub_source_quote_date`, `eur_rub_source_quote_date`, `cny_rub_source_quote_date` и соответствующие `*_freshness_days`. Freshness — число календарных дней между T и датой использованной опорной котировки; `broad_rub_freshness_days` равен максимальному возрасту среди трёх источников. Нулевое значение означает совпадение дат.

## Broad RUB factor

Для каждой опорной валюты доходность на N quote observations равна `P_t / P_(t-N) - 1`. Затем:

```text
broad_rub_return_N = mean(USD_RUB_ret_N, EUR_RUB_ret_N, CNY_RUB_ret_N)
```

Среднее вычисляется только при наличии всех трёх компонентов. Положительное значение обычно соответствует ослаблению RUB к корзине валют, отрицательное — укреплению. Корзина равновзвешенная и не является официальным индексом.

```text
corridor_specific_return_N = corridor_return_N - broad_rub_return_N
```

Положительное значение означает, что RUB-цена валюты получателя росла сильнее общей опорной корзины; отрицательное — слабее или снижалась сильнее.

## Нормализованный broad factor

Для returns USD/EUR/CNY горизонтов 1, 3 и 5 рассчитывается:

```text
z_t = (x_t - mean(x_(t-60)...x_(t-1))) / std(x_(t-60)...x_(t-1))
broad_rub_z_N = mean(USD_z_N, EUR_z_N, CNY_z_N)
```

Текущий return исключён из mean/std. Используется выборочное стандартное отклонение (`ddof=1`), глобальные статистики и будущие наблюдения не используются.

## Ограничения

- Quote observation не равен календарному дню.
- Freshness может отличаться между валютами; устаревшее значение не считается новой котировкой.
- Implied cross-rate не учитывает комиссии, спреды и исполнимые курсы сервисов переводов.
- Broad factor чувствителен к равным весам USD/EUR/CNY и отражает совместное движение RUB-котировок, а не причинный макроэкономический фактор.
- `corridor_specific_return` — относительный статистический остаток, а не доказательство специфического события в стране получателя.
