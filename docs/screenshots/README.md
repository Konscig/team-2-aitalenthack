# Порядок экранов текущего пути перевода

1. **`IMG_1856.PNG` — Платежи:** точка входа, раздел «Переводы» → «Переводы за рубеж».
2. **`IMG_1857.PNG` — Выбор страны:** выбор направления перевода, в том числе Таджикистана, Узбекистана, Кыргызстана, Казахстана и Армении.
3. **`IMG_1858.PNG` — Выбор способа перевода в Таджикистан:** по номеру телефона, карты или счёта; на этом экране уже видны скорость, лимиты и комиссия каждого способа.
4. **`IMG_1859.PNG` — Ветка A: перевод по номеру телефона:** выбор счёта списания, получателя и ввод суммы; пример показывает состояние недостатка средств.
5. **`IMG_1860.PNG` — Ветка B: перевод по номеру карты:** ввод реквизитов получателя, суммы и счёта списания, затем переход к продолжению перевода.

> Экраны 4 и 5 — альтернативные ветки после шага 3, а не последовательные шаги одного перевода.

> Источник экранов — публичная актуальная версия приложения, что соответствует уточнению Q&A кейсодателя. Экраны с итогом, курсом исполнения и подтверждением пока нужно дополнить: без них нельзя утверждать, как публичный рыночный сигнал соотносится с фактическими условиями операции.
