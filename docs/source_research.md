# Исследование источников курсов валют ЦБ РФ

Дата исследования: 2026-09-03. Этап ограничен source discovery: полный
пятилетний набор данных не загружался, features и labels не создавались.

## Выбранный официальный источник

Основной источник — официальный SOAP web-service Банка России `DailyInfo`:

- документация: <https://www.cbr.ru/development/DWS/>;
- endpoint: `https://www.cbr.ru/DailyInfoWebServ/DailyInfo.asmx`;
- WSDL: `https://www.cbr.ru/DailyInfoWebServ/DailyInfo.asmx?WSDL`;
- transport: HTTPS, SOAP 1.1, HTTP POST;
- namespace и SOAPAction: `http://web.cbr.ru/`;
- формат ответа: XML; XML-методы возвращают «простые» XML-документы внутри
  SOAP Envelope.

Документация ЦБ сообщает, что данные web-service опираются на базу данных
официального сайта. ЦБ также рекомендует минимизировать число вызовов и
использовать промежуточное хранение ответов.

### Используемые методы

`EnumValutesXML(Seld=false)` возвращает справочник ежедневно устанавливаемых
валют. Поля записи:

- `Vcode` — внутренний код ЦБ;
- `Vname`, `VEngname` — названия;
- `Vnom` — номинал;
- `VcommonCode` — общий код для связи версий валюты;
- `VnumCode` — цифровой ISO-код;
- `VcharCode` — символьный ISO-код.

Именно этот метод должен динамически связывать требуемый ISO-код с внутренним
кодом перед запросом истории. Внутренние идентификаторы не должны быть
production-конфигурацией: документация предупреждает, что код может измениться
при изменении названия, номинала или кода валюты.

`GetCursDynamicXML(FromDate, ToDate, ValutaCode)` возвращает историю одной
валюты. Фактически полученные поля каждой записи:

- `CursDate` — дата действия курса с часовым поясом `+03:00`;
- `Vcode` — внутренний код валюты;
- `Vnom` — номинал;
- `Vcurs` — raw rate: рублей за `Vnom` единиц валюты;
- `VunitRate` — рублей за одну единицу валюты.

Официальный HTTP/XML-интерфейс
<https://www.cbr.ru/development/SXML/> также предоставляет справочник
`XML_valFull.asp` и историю `XML_dynamic.asp`. Он пригоден как отдельный
контролируемый источник, но переключение на него не должно происходить тихо:
смена endpoint должна фиксироваться в manifest и provenance.

| KGS | R01370 | 417 | 100 | Som |
| AMD | R01060 | 051 | 100 | Armenian Dram |
| KZT | R01335 | 398 | 100 | Tenge |

| EUR | R01239 | 978 | 1 | Euro |

Raw response и provenance:

- `data/raw/source_discovery/enum_valutes.xml`;
- `data/raw/source_discovery/enum_valutes.xml.metadata.json`;
- извлеченный snapshot: `data/raw/source_discovery/target_currency_mapping.json`.

Важно: `Vnom` различается между валютами и потенциально может меняться во
времени. Поэтому pipeline обязан хранить raw `Vnom` в каждой исторической
строке и использовать `VunitRate` либо проверяемую формулу
`unit_rate = Vcurs / Vnom`. Делить ряд только на сегодняшний номинал нельзя.

Параметры теста:

- метод: `GetCursDynamicXML`;
- `FromDate=2024-01-10T00:00:00`;
- `ToDate=2024-01-19T00:00:00`;
- `ValutaCode=R01235`, причем значение получено из `EnumValutesXML`;
- время запроса: `2026-09-03T09:28:42.816611+00:00`;
- HTTP status: `200`;
- SHA-256 raw response:
  `24933a4615786fd14af59d9b09f34e05a0a7859ecc8cdac4cb360aba5a0ced82`.

Получено 8 наблюдений за 10 календарных дней. Отсутствие строк за некоторые
дни ожидаемо для календаря публикаций и не должно заполняться придуманными

Автоматический результат discovery находится в
`data/raw/source_discovery/validation_summary.json`. Probe был выполнен командой
`python scripts/source_discovery.py`; он завершается ошибкой, если хотя бы одной
валюты нет, ответ пуст, unit rate не согласован с raw rate и nominal или менее

созданных raw-файлов намеренно запрещен, чтобы не уничтожить snapshot; для
нового discovery run нужно указать в скрипте новый каталог `OUT`.

## Семантика курса для проекта

Целевой показатель — рубли за одну единицу валюты получателя:

```text
rub_per_recipient_currency = VunitRate = Vcurs / Vnom
```

При фиксированной сумме RUB более низкий `rub_per_recipient_currency` означает,
что за рубли можно получить больше единиц валюты получателя, то есть момент
выгоднее отправителю. Обратный показатель допустим как вычисляемый:

```text
recipient_currency_per_rub = 1 / rub_per_recipient_currency
```

Курс ЦБ — официальный ориентир, а не фактический курс исполнения перевода
Альфа-Банка. Это ограничение необходимо сохранять во всех отчетах и моделях.

## Вывод source discovery

Официальный машинно-читаемый источник существует, возвращает требуемые поля и
все восемь нужных валют. Mapping может и должен разрешаться динамически через
справочник ЦБ. Тестовая история USD получена из SOAP и подтверждена публичной
страницей ЦБ без расхождений по трем проверенным датам.
