# Product resync — новая продуктовая рамка

> Статус: рабочая гипотеза · 3 сентября 2026 · ветка `product/resync-concept`

Эта папка не исправляет задним числом существующие документы в `docs/`. Она нужна,
чтобы заново выбрать продуктовую ставку до того, как мы перепишем Lean Canvas,
User Story Map, Journey Maps и прототип.

## Что меняем

Старая рамка начиналась с вопроса: «в какой момент отправить пуш о выгодном
курсе?». Новая начинает с бизнес-задачи: **как увеличить инкрементальный объём
регулярных трансграничных переводов, помогая клиенту вовремя и без давления
вернуться в знакомый путь перевода**.

Рынок и модель остаются важны, но только как доказуемый и объяснимый повод для
контакта. Продукт не предсказывает курс, не обещает выгоду и не подменяет выбор
клиента.

## Чего здесь нет

- утверждений о реальном поведении клиентов: у команды пока нет продуктовых
  когорт или результатов пилота;
- прогноза курса, торговых советов, обещаний конечной суммы либо «гарантированно
  выгодного момента»;
- замены конкурсной ML-задачи: её метрики остаются отдельным доказательством
  качества сигнального слоя;
- расчёта банковской маржи, которого нельзя честно сделать по открытому курсу.

## Следующий артефакт после решения команды

Если концепт принят, переносим выбранные решения в новую версию Lean Canvas и
User Story Map, а затем пересобираем оба Journey Map и сценарии прототипа. Старые
документы сохраняем как версию `v1`, а не перезаписываем без следа.
