# Комплект продуктовых материалов

Это компактный набор для текущей итерации **signal-assisted transfer для
трансграничного перевода**. Signal — ключевой продуктовый триггер; hook и quote
помогают клиенту его понять и использовать. Набор фиксирует принятые решения и не заменяет
детальные исследования, ML-отчёты и технические спецификации.
