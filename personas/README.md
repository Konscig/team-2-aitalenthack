## Как использовать в интервью

- Рекрутировать людей по поведению, а не по имени, стране рождения или возрасту: регулярность перевода, коридор, срочность, возможность выбрать день.
- Проверять факты из блоков «Гипотезы для проверки»; не подтверждать персону вопросами с подсказкой.
- После интервью заменять предположения наблюдениями и при необходимости объединять или разделять сегменты.
